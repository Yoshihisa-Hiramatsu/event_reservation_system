# LINE予約管理システム v2（GASコード）導入手順

v1からの主な変更点

- 複数の開催を同時に募集できます（LINEで番号を選んでもらいます）
- 質問文・項目名・使う/使わない（ON/OFF）・返信メッセージを、開催シートの「設定」タブで変えられます
- 業種別のひな形が3種類（美容／見学会・デモ／個別相談会）
- 親シートのメニューから、ひな形を複製して新しい開催を作れます
- 当日スケジュール・要確認リストの作成も親シートのメニューに移りました（開催別シートにGASは不要です）

## 1. コードを親シートのApps Scriptに作る

これまで開催別シート側のApps Scriptに入れていたコードは、**親シートのApps Scriptにまとめます**。
親シートにApps Scriptがまだない場合は、新規作成になります。

1. 親シート（開催マスタが入っているファイル）を開き、「拡張機能」→「Apps Script」
2. 最初からある `コード.gs`（空の関数）は削除してかまいません
3. 次の15ファイルを、同名で作って貼り付けます（「+」→「スクリプト」）
   `Config.gs` `Util.gs` `Settings.gs` `StateManager.gs` `LineApi.gs` `SheetUtils.gs` `EventSelector.gs`
   `Identity.gs` `RegisterFlow.gs` `CancelFlow.gs` `ConfirmFlow.gs` `ChangeFlow.gs` `EventAdmin.gs` `Menu.gs` `Main.gs`
4. 「プロジェクトの設定」（歯車）→「スクリプト プロパティ」に2つ追加
   - `CONTROL_SHEET_ID` : **親シート**のスプレッドシートID（URLの `/d/` と `/edit` の間）
   - `LINE_CHANNEL_ACCESS_TOKEN` : これまでと同じトークン（旧プロジェクトの同じ画面からコピーできます）
5. 「デプロイ」→「新しいデプロイ」→種類「ウェブアプリ」→実行ユーザー「自分」・アクセスできるユーザー「全員」→デプロイ
   初回は権限の承認が出ます。表示された**新しいURL**をコピーします
6. LINE Developersの「Messaging API設定」で、Webhook URLを**新しいURLに置き換え**、「検証」を押して成功を確認します
7. 親シートを再読み込みすると、上部に「予約管理」メニューが出ます

以後のコード修正は、コードを貼り替えて「デプロイ」→「デプロイを管理」→鉛筆アイコン→
バージョン「新しいバージョン」→「デプロイ」で反映します（この場合はURLが変わりません）。

旧プロジェクト（開催別シート側）のWebhookは、手順6で切り替えた時点で使われなくなります。
新しい方で動作確認ができるまでは、旧プロジェクトを消さずに残しておいてください。

## 2. ひな形を登録する

1. 3つのxlsx（美容／見学会デモ／個別相談会）をGoogleドライブにアップロードし、Googleスプレッドシートとして開いて保存します。
2. 親シートに「ひな形」タブを作り、次のように入力します（A1=ひな形名、B1=URL）。

   | ひな形名 | URL |
   |---|---|
   | 美容イベント | （美容のスプレッドシートのURL） |
   | 見学会・デモ | （〜） |
   | 個別相談会 | （〜） |

## 3. 開催を作る

1. 親シートを開き直し（再読み込み）、上部メニュー「予約管理」→「新しい開催を作成（ひな形から複製）」
2. 開催日 → 開催名 → ひな形の番号を入力
3. 初回は権限の承認（Googleドライブへのアクセス）が出るので承認し、もう一度メニューを実行
4. 親シートと同じフォルダに `開催年月日_開催名` のファイルができ、開催マスタに追記されます（ステータスは「準備中」）
5. 新しいファイルの「設定」「対応者一覧」「枠マスタ」「メニュー」を入力
6. 準備ができたら、開催マスタのステータスを「募集中」にする

## 4. 「設定」タブ

列：A=内部キー（変更しない）／B=表示名／C=LINEの質問文／D=使う(ON/OFF)／E=選択肢／F=補足（読まれません）

- C列が空欄、または「…」で終わる文は「未設定」とみなし、標準の質問文になります
- `guest`（ゲスト）と `slot`（時間枠）は必須で、OFFにしても無効です
- `organizer` をOFFにすると、動員する人を聞かず、ゲスト本人の名前だけで予約・キャンセル・変更を探します
- `staff` のE列は「対応者一覧の最後に付ける選択肢」（例：誰でも良い）
- `note` のE列の先頭は「特になし」に当たる言葉（これが選ばれたら空欄で保存）
- `msg_accepted` `msg_pending` は返信メッセージ。`{no}` は予約番号に置き換わります
- 表示名を変えたら、メニュー「予約タブの見出しを設定に合わせる」で予約タブの見出しも更新できます
- 設定タブが無い古い開催シートも、標準の文言（美容版）のまま動きます

## 5. 複数開催のLINEでの流れ

- 募集中が2件以上のとき、「登録」「キャンセル」「登録確認」「変更」を送ると、最初に開催を番号で選びます
- 募集中が1件だけなら、選択は飛ばして進みます
- 同時に選べるのは12件までです（LINEのボタンが13個まで）

## 6. 当日スケジュールと要確認リスト

1. 前日ミーティングで、予約タブの「確定担当者」「確定枠番号」を埋める
2. 親シートのメニュー「予約管理」→「当日スケジュールと要確認リストを更新」→開催を選ぶ
3. 同じ担当者・同じ枠に複数ゲストがいるセルはオレンジ色になり、件数が表示されます
4. 要確認リストには、ステータスが「要確認」の予約が並びます

## 7. 旧ひな形について

旧「予約管理_開催別ひな形」にGASを入れていた場合、そのGASプロジェクトは不要です。
複製すると一緒に複製されてメニューが二重に出るため、旧ひな形のApps Scriptは削除してください。
すでに動いている開催シートは、そのまま使えます（予約タブの列位置は変わっていません）。

## 8. 変更・修正のメモ

- 予約タブは「見出しの文字」ではなく「列の位置」で読むようになりました。見出しは自由に変えられますが、**列の順番は変えないでください**
- 対応者一覧・メニューも1列目（A列）を読みます。見出しの文字は自由です
- 「要確認」の予約を変更しても、ステータスが「変更済」に上書きされず「要確認」のままになります
- クイックリプライは13個までのため、メニューは12項目まで・時間枠と対応者は13個までが目安です

## 既知の制限

- 会話状態は30分操作がないと消えます（`Config.gs` の `STATE_CACHE_SECONDS`）
- 同じ名前のゲストを同じ動員者が2人登録するとキャンセル・変更で区別できません
